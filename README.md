# SignalForge

SignalForge is a local-first financial research agent for turning public company filings, macroeconomic series, and market data into auditable intelligence.

The project is being built for the AMD AI DevMaster Hackathon Track 2, with core inference designed to run locally on AMD Radeon GPUs through ROCm.

## Goal

Build a private research desk where specialist agents can:

- retrieve financial and macroeconomic evidence;
- calculate deterministic financial metrics;
- reason over accounting context;
- preserve local memory;
- produce clear, evidence-grounded analysis.

## Status

Early public repository scaffold. The implementation will be added as the product architecture and runtime are finalized.
