# SignalForge Demo Script

Final duration: 4 minutes 26 seconds (266.496 seconds). The final cut combines authentic product
footage from the public fixture replay with current, hash-bound architecture and evidence slides.
It never presents a replay as a new live inference run.

## Recording Rules

- Show the Radeon workspace identity and readiness before the product.
- Use the clean investor view first; open technical detail only when explaining it.
- Label the Microsoft/NVIDIA screen capture as a public fixture replay with no direct peer ranking.
- State separately that the current authority supports five governed peer lanes, including
  NVIDIA/AMD.
- Keep prompts, answers, credentials, source bodies, and private traces out of the recording
  controls and logs.
- Show actual plan progression, evidence, receipts, memory controls, and Mission Control.
- Include one safe failure or abstention.
- End with the immutable source, image digest, and public repository.

## Sequence

### 0:00-0:47 - Product Promise And Capabilities

Introduce SignalForge as a private financial research desk that combines public evidence, local
Radeon inference, deterministic financial authority, and inspectable agent work.

### 0:47-1:30 - Architecture And Numerical Silence

Show core local inference, optional bounded Radeon API specialists, Numerical Silence, retention
off by default, and the expandable plan.

### 1:30-2:06 - Governed Research Journey

Show the public fixture replay while interpretation, parallel specialists, retrieval,
deterministic tools, independent critics, and final validation progress. Keep the replay label
visible and do not characterize Microsoft/NVIDIA as a direct peer ranking.

### 2:06-2:29 - Investor Result

Show the released research chapters, evidence links, calculation receipts, accounting caveats,
monitoring conditions, and no unsupported winner.

### 2:29-3:04 - Memory, Permissions, And Mission Control

Enable retention explicitly, save the safe projection, inspect the case library, export it, then
delete it. Explain that prompts, raw responses, source bodies, and hidden reasoning are never
stored.

Open the local case timeline and Mission Control. Correlate plan, route, evidence, engine, privacy,
and Radeon signals while keeping model bodies protected.

### 3:04-3:32 - Radeon Runtime And Failure Policy

Show local Gemma on ROCm, the bounded optional Radeon API route, local recovery, and fail-closed
behavior when core inference is unavailable.

### 3:32-4:00 - Radeon Model Selection And Optimization

Show the measured Gemma, Qwen, and Granite profiles. Explain that Gemma and Qwen passed `40/40`
contract checks, Granite passed `35/40`, and Gemma measured `3.28x` Qwen's median decode
throughput in this bounded workload. Then show the `29.17%` four-worker end-to-end improvement.
State that model, runtime, and precision differ and that this is not a universal ranking.

### 4:00-4:21 - Frozen Evidence And Limitations

Show 180/180 runtime and contract completion, zero false-release candidates in the bounded
model-assisted review, the 5h28 soak, immutable identity, and the responsible-use boundary.

### 4:21-4:26 - Close

Close with the public repository and immutable release identity.
