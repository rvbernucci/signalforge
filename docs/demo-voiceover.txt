SignalForge is a private, local-first financial research workspace for independent investors.

Instead of asking one language model to calculate, remember, retrieve, and judge its own answer,
SignalForge separates those responsibilities.

A typed Go planner interprets the research goal. Point-in-time retrieval assembles authorized
public evidence. Deterministic engines calculate financial quantities and issue hash-verifiable
receipts. Specialist agents work in parallel, then independent evidence and risk critics challenge
the draft before a local Radeon model performs final synthesis.

This is Numerical Silence: the model can explain approved financial evidence, but it does not
become the source of record for the numbers.

Here we start a governed NVIDIA and AMD comparison. The investor sees a clean workspace, while the
execution plan can expand to show interpretation, retrieval, tools, specialists, critics, repair,
and release.

The final answer contains cited evidence, deterministic calculations, accounting caveats, scenario
assumptions, and monitoring conditions. If definitions, periods, units, or accounting perimeters
do not support a direct comparison, SignalForge narrows the claim or abstains.

Research memory is local and off by default. The user can explicitly retain the safe released
projection, inspect it, export it, and delete it. Prompts, raw model responses, source bodies,
credentials, and hidden reasoning are excluded.

Mission Control correlates the same run across agent stages, model routes, evidence, engines,
failures, and Radeon telemetry without exposing protected content.

Core inference runs locally on AMD Radeon through ROCm using Gemma 4 26B Q4_0. A bounded
organizer-provided Radeon API can accelerate selected context specialists, but local critics,
final synthesis, deterministic authority, and release validation remain under SignalForge
control.

The current candidate completed one hundred eighty of one hundred eighty Radeon journeys and
release contracts, ten of ten repeated financial-quality journeys, and a five-hour twenty-eight
minute soak with no observed allocated-VRAM growth.

SignalForge can make mistakes. It is research software, not an audit, investment recommendation,
trading system, or guarantee. Important information should be verified before financial
decisions.

SignalForge: private financial research, with visible evidence and bounded authority.
