SignalForge is a private, local-first financial research workspace for independent investors.

Public filings, investor-relations material, macroeconomic series, and market observations are
abundant. What is scarce is a disciplined process that keeps reported facts, deterministic
calculations, assumptions, counterarguments, and uncertainty separate.

SignalForge helps an investor understand how a business earns money, examine financial quality,
connect economic forces to explicit transmission mechanisms, compare companies within governed
boundaries, inspect valuation scenarios, and identify what would invalidate a thesis. It does not
predict prices, execute trades, or provide personalized investment instructions.

The architecture separates interpretation from financial authority. A typed Go control plane owns
scope, evidence authorization, tool permissions, calculations, lineage, review gates, and
publication. Point-in-time retrieval assembles authorized public evidence. Eleven specialist and
control roles exchange typed packets and references rather than unrestricted chat transcripts.

This is Numerical Silence. Language models may explain verified relationships, but they do not
become the system of record for financial values. Eighty deterministic Go operations own every
authoritative number, period, unit, formula, comparison direction, and replayable receipt.

The interface footage uses the bundled public Microsoft and NVIDIA fixture to show the workflow.
It is a transparent product replay, not an authorized direct peer ranking. The current product
authority covers twenty United States technology companies and five separately governed peer
lanes, including NVIDIA and AMD.

The investor begins in a clean workspace. The execution plan can expand to show interpretation,
planning, evidence authorization, deterministic tools, parallel specialists, independent critics,
repair, and release validation without exposing hidden reasoning.

The released research case keeps the main answer readable while evidence, assumptions,
counterevidence, calculation receipts, accounting caveats, monitoring conditions, and limitations
remain one interaction away. When definitions, periods, units, or accounting perimeters do not
support a direct comparison, SignalForge narrows the claim or abstains.

Research memory is local and disabled by default. The user can explicitly retain only the safe
released projection, inspect it, export it, and delete it. Prompts, raw model responses, source
bodies, credentials, and hidden reasoning are excluded from durable memory and public telemetry.

Mission Control correlates the same run across plan stages, model routes, evidence, deterministic
engines, failures, privacy controls, and Radeon telemetry. Operators can inspect the process
without receiving protected content.

Core inference runs locally on AMD Radeon through ROCm using Gemma 4 26B Q4_0. A bounded
organizer-provided Radeon API can accelerate selected context specialists, but local critics,
final synthesis, deterministic authority, and release validation remain under SignalForge
control. If the optional route fails, the governed local path can recover. If core local inference
is unavailable, the product fails closed.

In the bounded Radeon model tournament, Gemma passed all forty contract checks and reached 86.46
median decode tokens per second. Qwen also passed forty of forty at 26.39 tokens per second, while
Granite passed thirty-five of forty at 24.99. We therefore selected Gemma for this workload, not as
a universal ranking. Four workers then reduced end-to-end time by 29.17 percent versus the passing
three-worker control.

These are application-specific engineering results, not universal model rankings or independent
human-ground-truth accuracy. SignalForge can make mistakes. It is research software, not an audit,
investment recommendation, trading system, or guarantee. Important information should be
verified before financial decisions.

SignalForge: private financial research, with visible evidence and bounded authority.
